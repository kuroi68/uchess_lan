# LAN-режим uchess

LAN-режим позволяет двум экземплярам `uchess` сыграть партию в одной локальной сети.

## Запуск партии

Для запуска нужны два компьютера в одной сети или два экземпляра приложения. На обоих экземплярах должен быть настроен UCI-движок, как и для обычной игры.

1. На компьютере хоста запустите `uchess`, введите `online`, затем нажмите `h`.
2. На компьютере клиента запустите `uchess`, введите `online`, затем нажмите `c`.
3. После подключения хост играет белыми и ходит первым. Клиент играет чёрными и делает ход после хода белых.

Ходы вводятся в обычной алгебраической нотации, например `e4` или `Nf6`. Сделать ход можно только в свою очередь. Имя игрока берётся из `whiteName` или `blackName` конфигурации; если там пусто или указано имя движка, используется имя пользователя операционной системы. В интерфейсе стороны явно помечены как `White` и `Black`.

## Требования сети

- Оба компьютера должны быть доступны в одной локальной сети с разрешённым UDP broadcast.
- Для поиска хоста используется UDP-порт `8081`.
- Для игровой TCP-сессии на компьютере хоста используется порт `8080`.
- Firewall должен разрешать входящие UDP-пакеты на порт `8081` и TCP-подключения на порт `8080`.
- Клиент подключается к первому найденному хосту. Выбор между несколькими найденными хостами пока не поддерживается.

Соединение не использует шифрование или аутентификацию. Не запускайте LAN-игру в недоверенной сети.

## Что добавлено

- Обнаружение хоста в локальной сети через UDP broadcast.
- Подключение клиента к хосту по TCP и обмен сообщениями игровой сессии.
- Обмен никами игроков и отображение ников с явным указанием цвета фигур.
- Передача локальных ходов сопернику и применение входящих ходов.
- Ограничение ввода ходов очередью и блокировка ходов до подключения.
- Очистка и обрезка динамических текстовых строк интерфейса, чтобы они не накладывались друг на друга.
